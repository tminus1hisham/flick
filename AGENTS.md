# Improvement backlog

Read `improvements.md` before planning app changes. Before finishing a task, review relevant items against the current implementation and verification results: remove completed or already implemented items, retain only unfinished portions, and add concrete worthwhile improvements discovered during the work. Merge duplicates and keep priorities current. Do not implement unrelated backlog items without user authorization.

Read `CLAUDE.md` for the project architecture, design conventions and validation guidance. Treat historical entries marked obsolete as historical context.
